# L'Amour — clickable prototype

A premium, swipe-free dating app concept: a voice concierge (Aura), explainable compatibility, and an agent that turns matches into booked dates.

**Live demo:** https://sivas-subramaniyan.github.io/lamour-app/

Open it in a wide desktop window and use the › arrow (top right) to walk the 28-step golden-path tour. On a phone it runs full-screen; the compass button opens the screen list.

```
npm install
npm run dev     # http://localhost:5179
npm run build
npm run check   # numerology + compatibility self-check
```

See BUILDING.md for the design system and conventions. Photos are Unsplash stand-ins; all people and venues are fictional.
